# 🌐 Personal Portfolio Website

A modern, responsive, and interactive portfolio website showcasing my skills, projects, achievements, and professional journey. Built with a clean UI, smooth animations, and optimized performance to create a great user experience across all devices.

## 🚀 Features

- 🎨 Modern and Responsive Design
- 📱 Mobile-Friendly Layout
- ⚡ Fast Loading Performance
- 👨‍💻 About Me Section
- 🛠️ Skills Showcase
- 📂 Projects Portfolio
- 📜 Education & Experience
- 🏆 Certifications & Achievements
- 📞 Contact Details
- 🔗 Social Media Links
- ✨ Smooth Animations and Transitions

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)

### Deployment
- GitHub Pages
